# TRYHUB

체험단 공고를 모아 신청 조건과 리뷰 일정을 관리하는 개인용 웹앱입니다.

## Phase 1 상태

- Next.js App Router, TypeScript, Tailwind CSS v4 기반 대시보드 화면
- 데모 데이터는 2026-11-13 조사 스냅샷이며 실시간 수집이나 신청 기능이 아닙니다.
- 무신사 레벨 1 계정에서 확인한 모집 공고는 모두 최소 레벨 2 조건이었습니다.
- Supabase Auth/DB, 외부 플랫폼 어댑터, SNS OAuth, AI, 제출 자동화는 아직 연결하지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 환경변수

현재 Phase 1에는 API 키가 필요하지 않습니다. 향후 연동을 위해 `.env.example`에 변수 이름만 정리했습니다.
